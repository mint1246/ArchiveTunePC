Existing behavior kept during the merge

  • Android R2 updater: retains the custom R2 manifest, artifact key selection, SHA-256 verification, version-code identity, and existing mint1246/ArchiveTunePC source ownership. Upstream's channel label ARTIFACT maps to the R2 manifest's legacy canary property so clients keep reading the current schema.
  • AI provider compatibility: OpenRouter, custom endpoint/model/prompt support, and detailed API test errors remain available in the merged settings design.
  • Home/social behavior: manual Home merges retain local friends and personalized recommendations, like-state synchronization, dismissal/undo behavior, and upstream remote feedback only for items with valid feedback tokens.
  • Clicked media identity: Desktop podcast queues preserve the explicitly selected episode ID; upstream playlist IDs are used for community cards.
  • Statistics: Android reset clears both database aggregates and the authoritative statistics store. Desktop keeps its separate audible-time tracker and does not derive official listening time from recommendation play history.
  • STEM playback: Desktop retains the six-source STEM order and the existing ONNX/DirectML runner plus live renderer path; this sync does not replace the audio engine or trim the packaged VLC/runtime support.
  • Lyrics presentation: translation remains an overlay on synchronized lyrics and preserves chord presentation, artwork-driven background, and glow effects rather than flattening the lyrics view.
  • Native Windows packaging: Desktop additions remain on the Graal/Nucleus Native Image and bundled VLC packaging path; JVM compile success alone is not treated as MSI verification.
  • Local worktree safety: unrelated original dirty changes were preserved, with recovery snapshots under .validation.
  • R2 and release operations: the custom manifest/hash updater contract remains intact, with the Desktop MSI directly at /releases/ArchiveTune-15.10.0.msi. Its public hash and EXE identity were verified; no GitHub release or source push was performed.

Build, resource, and CI decisions

  • Android compile SDK is 37.2 with NDK 30.0.16248370; the upstream automotive device flavor sets its own minimum SDK.
  • Android release metadata is version code 151, version name 15.1.0; Desktop display/build metadata is 15.10. Nightly Android builds can receive a CI-provided version name.
  • Desktop source and tests use JVM JDK 21 HotSpot; Native Image uses GraalVM CE 25.1.3 (Java 25.0.3) with MSVC 19.51. A command-scoped MSVC Rust toolchain fixed the GNU/MSVC opus.lib mismatch without changing global environment settings.
  • The Windows native dependency checkout now enables Git long paths so the generated Essentia/Eigen source tree can build; this fix is recorded in b056bbd, and the audio DLL build passed.
  • Build, PR, and release workflows provision Python 3.11 to generate translation-contributor credits before building.
  • Android uses AGP 9.4.0, Gradle 9.7.1, and Android Compose 1.12.1; Desktop retains Compose Multiplatform 1.11. Android QuickJS and the existing JVM cipher occupy separate platform modules. The existing ONNX/DirectML model runner is retained.
  • The Desktop 15.10.0 MSI is published at the requested direct R2 key /releases/ArchiveTune-15.10.0.msi; its SHA-256 is recorded in the public manifest and verified against the public download.
