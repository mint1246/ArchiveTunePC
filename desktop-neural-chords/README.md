# Desktop neural chord analysis

This module owns the existing cached local ChordMini analysis flow, including runner process management, model verification, result parsing and atomic cache writes. Hosts supply cache/model directories, a manifest URL, an audio-decoding callback and optional diagnostic reporting. The desktop app passes its real VLC decoder, preserving stream resolution and existing audio behavior. Songsterr source priority remains in the lyrics presenter, outside this module.

The module publishes experimental Maven Local coordinates `moe.rukamori.archivetune:desktop-neural-chords:0.1.0-SNAPSHOT`, with `chords-sdk`, `playback-core` and `desktop-model-runtime` as dependencies; the runner and model assets are not bundled. `examples/headless-chords` resolves and constructs the analyzer without running inference. The cache-reuse test, real subprocess cancellation test, desktop compilation and quick Graal native compile pass. Cancellation now terminates a worker while output reading is blocked, rather than waiting for the parent coroutine to finish. A live runner inference, cancellation on a real GPU worker, and installed-package operation have not been verified.
